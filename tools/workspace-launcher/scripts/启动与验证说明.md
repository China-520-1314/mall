# 一键启动与验证

双击根目录 `start-mall.bat` 启动完整商城。启动器读取根目录已有的 `mall.local.env`，无需每次手动连接数据库。

启动流程：

1. 以 UTF-8 读取数据库配置；当前进程中已设置的同名配置优先。
2. 对本机数据库地址，如果目标端口未监听且仅找到一个 MySQL Windows 服务，尝试启动该服务。远程数据库只检查连接，不操作本机服务。
3. 使用后端包自带的 JDBC 驱动，以配置中的账号连接数据库并执行 `SELECT 1`。不建库、不执行迁移、不修改业务数据。
4. 连接失败时输出 SQLState 和错误码，停止启动流程，保留已有应用进程。账号和密码不写入命令行或日志。
5. 连接通过后启动 Redis，核对应用端口进程归属，重启本项目服务，并等待四个服务就绪。

如果 MySQL 服务启动提示权限不足，请在 Windows 服务管理中启动 MySQL 后重试。数据库密码变更后需更新 `mall.local.env`；启动器不会猜测密码。

只检查配置和数据库、不重启应用：

```bat
start-mall.bat -CheckOnly
```

前台地址为 http://localhost:5173/ ，管理后台为 http://localhost:5174/ 。服务日志位于 `runtime/launcher-logs`。

## 本轮代码与验证

- 订单列表限制状态、页码和每页数量，每页最多 100 条；没有订单时返回空数组。
- 订单回归覆盖本人订单、他人订单、已删除订单、不存在的订单和非法分页。
- 数量输入修复小数边界计算、非法输入及禁用交互；列表图标处理缺省方向。
- 后端所选 18 项测试通过，前端会话 2 项、数量输入框 3 项测试通过。
- 后端打包及 H5 构建通过；一键启动、数据库实际登录、故意使用不可用端口后的失败退出均验证通过。
- 首页、商品搜索返回业务码 200；访客查询订单返回业务码 401；两个后端就绪状态为 UP。

数量输入框回归命令（在 `mall-app-web` 中执行）：

```bat
npm run test:number-box
```
